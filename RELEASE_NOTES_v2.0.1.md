# Classification of Pain Patterns v2.0.1

This is the canonical release associated with the revised manuscript.

## Scope

The release contains the public Figure 6 reproducibility workflow, deterministic
inference examples, model artifacts, de-identified processed features, fold
assignments, device-response calibration data, first-principles input files,
training and evaluation scripts, statistical-analysis scripts, and figure
regeneration scripts available in the repository at the tagged commit.

Raw animal photometry recordings are not redistributed. Their access status and
the boundary of the public package are documented in
`fig6_reproducibility/DATA_ACCESS.md`.

## Verification

`RELEASE_MANIFEST.csv` and `SHA256SUMS.txt` provide file sizes and SHA-256
hashes. The release archive is accompanied by a separate `.sha256` file so the
GitHub, Zenodo, and supplementary copies can be verified as byte-identical.

## Version status

This release supersedes manuscript references to v1.0.0, v1.0.2, and the
pre-release tag `figure6-v2.0.1`. The canonical manuscript-associated identifier
is `v2.0.1`.
