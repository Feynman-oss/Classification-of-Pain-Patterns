# Code and data availability for release v2.0.1

The canonical public release is:

- GitHub tag: `v2.0.1`
- GitHub release: https://github.com/Feynman-oss/Classification-of-Pain-Patterns/releases/tag/v2.0.1
- Licence: MIT
- Zenodo DOI: to be inserted after DOI reservation and before final publication

The public package includes code, model artifacts, de-identified processed
features, fold assignments, response-table calibration files, and figure source
data. Raw animal photometry recordings remain restricted and are not included.
See `fig6_reproducibility/DATA_ACCESS.md` for the access boundary.
