# Code and data availability for release v2.0.2

The canonical public release is:

- GitHub tag: `v2.0.2`
- GitHub release: https://github.com/Feynman-oss/Classification-of-Pain-Patterns/releases/tag/v2.0.2
- Licence: MIT

The public package includes code, exact environment files, model artifacts,
de-identified processed features, fold assignments, response-table calibration
files, and figure source data. The identical frozen ZIP archive is supplied as
Supplementary Code. Raw animal photometry recordings remain restricted and are
not included. See `fig6_reproducibility/DATA_ACCESS.md` for the access boundary.
